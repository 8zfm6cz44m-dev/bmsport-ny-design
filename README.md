# BMsport – förbättrat designförslag

Responsiv, statisk HTML-prototyp för Barth Motorsport AB. Ingen byggprocess krävs: öppna `index.html` eller kör `python3 -m http.server 8765` och besök `http://localhost:8765/`.

Designen använder BMsports befintliga logotyp, en lokalt beskuren bild från den publika webbplatsen och produktbilder från bmsport.se. Alla produktknappar leder till respektive riktig produktsida. Sök, kategorier och varukorg länkar också till den befintliga butiken. **Prototypen har ingen egen kassa eller WooCommerce-integration.** Priserna i denna statiska demo är ögonblicksbilder; kontrollera aktuellt pris på produktsidan.

För att uppdatera den befintliga GitHub Pages-sidan behöver innehållet i denna katalog publiceras i repot `8zfm6cz44m-dev/bmsport-ny-design`. Ändringar här påverkar inte den publicerade sidan förrän de har pushats.
